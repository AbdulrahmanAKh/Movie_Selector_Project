Desktop Architecture Overview

View Repository

CineVault is engineered with clean separation between SQLite persistence, PyQt5 user interface widgets, and cryptographic security layers.

Authentication & Security

Multi-user password hashing using Python hashlib (SHA-256) with support for passwordless 1-click continuation.

SQLite Relational Schema

Strict referential integrity between users and personal media libraries with cascading deletions (ON DELETE CASCADE).

60fps Hardware Animations

Utilizes QPropertyAnimation with cubic easing and QGraphicsDropShadowEffect for fluid card hover effects.

Declarative UI Templates

Layouts defined in Qt Designer XML (.ui files) and dynamically compiled at runtime via PyQt5.uic.
